# Security Policy

## Supported Versions

This project is under active development. Only the latest commit on the
`main` branch is supported with security updates.

| Version            | Supported          |
| ------------------ | ------------------ |
| `main` (latest)    | :white_check_mark: |
| older releases     | :x:                |

## Reporting a Vulnerability

We take security seriously. Please **do not** open a public issue for
security vulnerabilities.

To report a vulnerability privately:

1. Open a [private security advisory](https://github.com/stellar-payment-gateway/stellar-payment-gateway-sdk/security/advisories/new)
   on GitHub, **or**
2. Contact the maintainers directly with full details of the issue.

Please include as much of the following as possible:

- The affected contract/module and function(s).
- A description of the vulnerability and its impact.
- Steps to reproduce, including any test scenario.
- Any suggested fix, if known.

You should receive an acknowledgement within 5 business days. We ask that you
give us reasonable time to fix and release the issue before disclosing it
publicly.

## Smart Contract Disclaimer

These contracts handle funds on the Stellar network. They are provided as-is
and have not been audited by a third party. Deploy at your own risk and always
conduct your own security review before using them with real assets.
